# Human Atlas / BodyParts3D attribution

Bucky Lab incorporates skeletal geometry from the open-source **Human Atlas** project:

- Human Atlas: https://github.com/ashemag/human-atlas
- Anatomy source: BodyParts3D 4.0
- Anatomy data licence: **CC BY 4.0**
- Human Atlas application code licence: MIT

The Human Atlas project states that its packaged anatomy contains 2,234 individually selectable BodyParts3D meshes and that the anatomy data is licensed separately from the application code. The Bucky Lab build fetches the browser-ready anatomy assets from the Human Atlas repository and packages them under `public/models/human-atlas/` for deployment.

BodyParts3D is an adult male reference anatomy. It is an educational anatomical reference and does not represent every human structure or anatomical variation.

When redistributing Bucky Lab with these anatomy assets, retain this attribution and the applicable CC BY 4.0 terms.
